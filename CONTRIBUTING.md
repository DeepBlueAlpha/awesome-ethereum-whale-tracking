# Contributing to Awesome Ethereum Whale Tracking

Thanks for your interest in contributing! This list aims to be the most useful collection of Ethereum whale tracking resources on the internet.

## How to add an entry

1. Fork this repository
2. Add your entry to the appropriate section in `README.md`
3. Submit a pull request

## Entry format

Each entry should follow this format:

```
- [Tool Name](https://example.com) — One-line description of what it does and why it's useful.
```

- **Link** must point to a live, working URL
- **Description** should be one sentence, factual, and useful to someone evaluating the tool
- No marketing language — describe what it does, not how great it is

## What belongs on this list

- Live whale tracking platforms (free or paid)
- Datasets containing whale transaction data
- APIs that provide on-chain data useful for whale tracking
- Open-source libraries for interacting with Ethereum
- Block explorers with whale-relevant features
- Telegram channels and X accounts focused on whale activity
- Dune dashboards tracking whale behavior
- Educational content about whale tracking methodology
- Academic papers studying on-chain whale behavior

## What doesn't belong

- Projects that are abandoned or no longer maintained
- Tools that require a paid plan with no free tier AND no free trial (unless they're industry-standard)
- Duplicate entries (check if the tool is already listed)
- Self-promotional entries with no real utility to the community
- Anything that requires sharing private keys or seed phrases

## Quality standards

- Every link must work (no 404s)
- Every description must be accurate as of the submission date
- Entries should be placed in the correct category
- New categories can be proposed if they contain at least 3 entries

## Updating existing entries

If a tool has changed (rebranded, changed pricing, added/removed features), submit a PR updating the description. Include a brief note in the PR description about what changed.

## Code of conduct

Be honest. If you're submitting your own tool, that's fine — just make sure the description is factual and the tool genuinely belongs on this list. We include competitors side by side because that's what makes the list trustworthy.
